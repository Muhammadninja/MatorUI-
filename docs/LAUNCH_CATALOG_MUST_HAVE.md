# Mator.uz — Обязательные позиции к ПЕРВОМУ релизу

_Минимальный каталог, без которого запускаться нельзя. Это спека для сбора реальных данных у поставщиков._
_Заполнять в CSV (`prisma/data/oem-catalog-skeleton.csv`) → импорт `npm run seed:oem:csv`._

---

## Принцип
Не весь каталог сразу. К первому релизу — **топ-модели × топ-категории расходников/ходовки** (≈80% реальных заказов). Остальное добавляется после старта продавцами/поставщиками.

**Целевой минимум к запуску: ~250–400 реальных позиций** (Tier-1 модели × Tier-1 категории, с несколькими брендами на позицию).

## Категории (обязательные) — Tier 1
Это расходники и ходовка. Указан `slug` (для колонки `categorySlug`).

### Тормоза
- [ ] Передние тормозные колодки — `front-brake-pads`
- [ ] Задние тормозные колодки — `rear-brake-pads`
- [ ] Тормозные диски — `brake-discs`

### Фильтры
- [ ] Масляные фильтры — `oil-filters`
- [ ] Воздушные фильтры — `air-filters`
- [ ] Салонные фильтры — `cabin-filters`
- [ ] Топливные фильтры — `fuel-filters`

### Зажигание
- [ ] Свечи зажигания — `spark-plugs`
- [ ] Катушки зажигания — `ignition-coils-wires`

### Подвеска / рулевое
- [ ] Амортизаторы — `shock-absorbers`
- [ ] Шаровые опоры — `ball-joints`
- [ ] Рулевые наконечники — `steering-racks-tie-rods`
- [ ] Стойки стабилизатора — `stabilizer-links-bushings`

### Двигатель / ремни
- [ ] Комплект ГРМ — `timing-belt-kits`
- [ ] Ремни навесные — `accessory-drive-belts`

### Охлаждение
- [ ] Водяные помпы — `water-pumps`
- [ ] Термостаты — `thermostats`

### ТО / жидкости
- [ ] Моторное масло 5W-30 — `motor-oil-5w30`
- [ ] Моторное масло 5W-40 — `motor-oil-5w40`
- [ ] Антифриз — `antifreeze`

### Прочее (ходовое)
- [ ] Щётки стеклоочистителя — `wiper-blades`

**Итого Tier 1: 21 категория.**

## Что должно быть в КАЖДОЙ позиции (обязательные поля)
| Поле | Обязательно | Пример |
|---|---|---|
| Название (`title`) | да | Тормозные колодки передние Cobalt |
| Бренд (`brand`) | да | Hi-Q / NGK / Gates / Chevrolet GM |
| Модель(и) (`models`) | да | `Cobalt\|Gentra` |
| Подкатегория (`categorySlug`) | да | `front-brake-pads` |
| OEM + кросс (`oemNumbers`) | да | `95939923\|SP1362` |
| Цена в сумах (`priceUzs`) | да | `210000` |
| Остаток (`stockQty`) | да | `10` |
| Фото | желательно | URL (иначе плейсхолдер) |

## Критерий готовности каталога к релизу
- [ ] Все Tier-1 модели × Tier-1 категории закрыты **реальными** позициями (OEM + цена + остаток)
- [ ] Минимум 1 позиция на каждую клетку матрицы; на ходовые (колодки, фильтры, свечи, масло) — 2–3 бренда
- [ ] Цены актуальные (проверены с поставщиком)
- [ ] OEM-номера сверены (правильная деталь на правильную модель)
- [ ] Проверено на проде: `?make=Chevrolet&model=<модель>` возвращает позиции по всем Tier-1 категориям
- [ ] Поиск по артикулу находит деталь (`?q=<OEM>`)
