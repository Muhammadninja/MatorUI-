SEARCH PAGE BACKEND HANDOFF

Screen purpose:
- Search/discovery landing page.
- Current UI contains 5 data-driven areas:
  1. Smart search header
  2. Quick filter chips
  3. Catalogue horizontal carousel
  4. Promo banner / sponsored placement
  5. Top Featured preview grid
- This screen should be easy to hydrate from one aggregated endpoint or from separate section endpoints.

Recommended REST approach:
- Preferred: GET /search/home
- Alternative split endpoints:
  - GET /search/quick-filters
  - GET /search/catalogue
  - GET /search/promo-banners
  - GET /search/top-featured-preview

Recommended query params from frontend:
- query: string
- quickFilter: string
- page: number
- pageSize: number
- includeCatalogue: boolean
- includePromotions: boolean
- includeTopFeatured: boolean

Current default query payload example:
- query: ""
- quickFilter: "Trending now"
- page: 1
- pageSize: 10
- includeCatalogue: true
- includePromotions: true
- includeTopFeatured: true

Aggregated response fields expected by frontend:
- requestId: string
- query: string
- selectedQuickFilter: string | null
- quickFilters: SearchQuickFilterItem[]
- catalogue: SearchCatalogueItem[]
- promoBanners: SearchPromoBannerItem[]
- topFeaturedPreview: SearchTopFeaturedItem[]
- websocket: SearchPageSocketConfig
- snapshotVersion: string

Smart search header actions that backend may support:
- typed text query
- voice search trigger result payload (if supported later)
- image search trigger result payload (if supported later)
- notification badge/count payload (optional)

SearchQuickFilterItem fields:
- id: string
- label: string
- slug: string
- selected?: boolean
- icon?: string
- count?: number
- query?: string

Top Featured preview notes:
- Current search page shows a small preview grid.
- "View all" routes to the dedicated Top Featured page.
- Keep item field names aligned with the Top Featured backend contract when possible.

Recommended WebSocket channel for live refresh:
- search_home:feed

Recommended WebSocket events:
- search_home.snapshot
- search_home.quick_filters.updated
- search_home.catalogue.updated
- search_home.promo.updated
- search_home.top_featured.updated

SearchPageSocketConfig fields:
- channel: string
- room: string
- events: string[]

WebSocket message fields:
- event: string
- snapshotVersion: string
- timestamp: ISO string
- requestId?: string
- section?: quickFilters | catalogue | promoBanners | topFeaturedPreview
- itemId?: string
- payload?: SearchQuickFilterItem | SearchCatalogueItem | SearchPromoBannerItem | SearchTopFeaturedItem | object
