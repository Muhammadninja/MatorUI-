HOW TO READ THIS
  • "REFERENCE / LOOKUP DATA" = catalog tables you seed once and rarely change.
    This is the "car brands / car models" data the request is about.
  • "CATALOG CONTENT" = the actual products/parts inventory + supplier brands.
  • "USER-GENERATED DATA" = created per-user at runtime (schema only, no seed).
  • "ENUMS / VALUE SETS" = fixed value lists to enforce/validate against.
  • Field names come straight from the current TypeScript types so the backend
    contract matches the app with zero client changes.

A3. VEHICLE GENERATIONS                           [table: vehicle_generations]
--------------------------------------------------------------------------------
Why it matters: OEM part numbers differ per generation, even for "the same"
model. This is the fitment key parts-search filters on.
Fields:
  id            string (slug, PK)   e.g. "cobalt-p2"
  modelId       string (FK->models)
  label         string  (local name) e.g. "Position 2", "Nexia 3", "Malibu 2"
  yearRange     [number, number]     e.g. [2016, 2018]  (use 2099 for "current")
  internalCode  string? (mfr codename) e.g. "T250", "XL"
  active        boolean (still sold new -> drives "discontinued" badge)

Seed rows currently (19): Cobalt P1-P4, Malibu 1-2, Nexia 2-3, Lacetti,
  Gentra, Spark M400, Tracker 3, Captiva 5, Onix, Damas 2, BYD Chazor/Song Plus/Han.

B1. PARTS / PRODUCTS                              [table: products / catalog_items]
--------------------------------------------------------------------------------
The sellable auto-parts inventory. Combined shape from MatorProduct + CatalogItem:
Fields:
  id           string (PK)
  title        string          e.g. "Ceramic Brake Pads — Front"
  oem          string          OEM number, e.g. "GD1234-8Z", "90915-YZZE1"
  brand        string          supplier/part brand (see B2)
  categoryId   string (FK->catalog_systems / category)
  region       enum? (china|europe|russia|korea|usa; else inferred from brand)
  priceUzs     number          numeric price in som (for sort/range filtering)
  priceLabel   string          e.g. "UZS 850,750" / "Starting at"
  was          number?         struck-through original price (for SAVE %)
  rating       number          e.g. 4.8
  reviews      number          e.g. 214
  inStock      boolean
  isOem        boolean         drives "OEM" quick filter
  featured     boolean
  images       string[]        image URLs
  specs        [{ label, value }]   key/value spec rows
  fitment      { brandId, modelId?, generationId?, trimId?, engineId? }[]
               (which vehicles this part fits — the critical join)

Sample seed (10 demo parts today): Ceramic Brake Pads, Genuine Oil Filter,
  Iridium TT Spark Plug, Cabin Air Filter, Wiper Blade Set, Alternator 130A,
  Serpentine Drive Belt, Brake Rotor, Engine Air Filter, 12V AGM Battery.
