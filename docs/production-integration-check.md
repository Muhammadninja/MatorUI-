- Manifest: `name=production`, `apiBaseUrl=https://api.mator.uz`, `httpDomains=""`, `allowDevOtp=false`; dotenv отключён штатным скриптом.
- В симуляторе iPhone 16 Pro / iOS 18.3 видна маркировка `PRODUCTION · api.mator.uz`. Локальный синтетический аккаунт предварительно вышел.
- Локальные API/БД и Metro:8082 сохранены отдельно. Конфигурационные файлы и схема реальной БД не менялись; seed не переносился. Обратимые операции корзины и выбора автомобиля выполнялись только через реальный backend и затем восстановлены.

## Подтверждено на реальном API
- `GET /v1/catalog/parts`: HTTP 200; страницы 100 + 59, всего 159 уникальных товаров; `part_local_*` отсутствуют.
- Реальные категории и количества загрузились в native Home; справочник вернул 10 категорий, количества RU/UZ совпали.
- Карточка `part_stock_6096`: HTTP 200, цена 2 210 000 UZS совпала со списком; изображение из ответа доступно, HEAD 200.
- Ошибки поиска: `SOLITE5741AVG` даёт 1 товар в каталоге и 0 в поиске; `фильтр` при `price_asc` и `price_desc` возвращает одинаковые ID и немонотонные цены; `under_1k` всё ещё возвращает товары по 30 000+ UZS; запрос `ый` сообщает 30 результатов, возвращает 20 и `nextPageToken=null`.
- Публичный скрипт выполнял только чтения; POST в нём использовался исключительно для `/v1/search`, без Authorization. Первичный пробный запрос с неподдерживаемым `limit` вернул 400; штатная пагинация использует `page_size`.
- Свежие публичные ответы: `/tmp/mator-production-public-evidence.json`; manifest: `/tmp/mator-production-runtime-manifest.json`. Содержимое сессий и токены не записывались в отчёт.

- Из карточки `part_stock_6026` добавлена реальная деталь за 110 000 UZS: в корзине стало 2 строки, промежуточный итог 573 667, итог 603 667 UZS. Добавленная строка удалена; исходная корзина восстановлена и повторно проверена после перезагрузки (1 строка, итог 493 667 UZS).
- Garage загрузил два существующих автомобиля. Переключение Cobalt → Malibu → Cobalt прошло; исходный Cobalt оставался активным после перезагрузки. Подбор для Cobalt показал 44 результата.

## Дополнительное исправление текущего запуска
Поиск создавал коммерческие бейджи по хешу ID, когда сервер их не прислал. Убран синтетический fallback в `search-result-row/variant.ts`; серверные метки остаются. После перезагрузки native-поиск визуально проверен: выдуманных «Хит продаж»/«Хорошая цена» на исходных карточках больше нет.

910 ранее пройденных тестов повторно не запускались. Для дополнительного изменения выполнены 12 точечных тестов, typecheck и production iOS JS/Hermes export (`/tmp/mator-production-search-export`); всё прошло. Это не native Xcode rebuild.
