# Handoff: корзина и изоляция сессий

## Изменено
- Корзина принимает канонические цены и количества сервера, сохраняет дробные UZS.
- Записи и чтения упорядочены; старые ответы не заменяют новые действия. Откат ошибки затрагивает только нужную строку и сохраняет её порядок.
- Кеш корзины разделён по пользователям и гостю. Старый кеш без владельца намеренно не восстанавливается.
- Выход и смена аккаунта сбрасывают Garage, активный автомобиль и карту серверных ID корзины; отложенные ответы, повторы и авторизация прежней сессии отбрасываются.
- Запись авторизации и активного автомобиля упорядочена. Убрано открытое логирование токенов; нативный тайм-аут Expo нормализован.

## Проверено локально
- iPhone 16 Pro / iOS 18.3, локальный API и синтетический аккаунт: заполненная корзина, быстрые нажатия 2 → 5 → 2, пересчёт сумм.
- При приостановленном локальном API: тайм-аут с откатом; выход во время обновления. После возобновления API и перезагрузки приложения корзина и Garage оставались пустыми, активный автомобиль не возвращался.
- Заполненный Garage: три автомобиля, переключение активного, длинные русско-узбекские названия. Внешний вид заполненных экранов проверен в светлой теме.
- 910 тестов прошли; typecheck прошёл; production iOS JS/Hermes export прошёл (`/tmp/mator-session-audit-export`). Это не native Xcode rebuild и не подтверждение работы с production API.

## Проверено только тестами
- Смена A → B без промежуточного гостевого состояния, ошибка загрузки нового аккаунта, запоздалые успешные и ошибочные ответы прежнего аккаунта.
- Отложенные чтения/записи корзины, карта ID транспорта, поздний refresh профиля/токена, гидратация и сохранение после выхода.
- Изоляция кеша гостя/аккаунтов и активного автомобиля, запоздалые изменения Garage.
- Исправление текста нативного тайм-аута покрыто тестами; повторный визуальный тайм-аут после нормализации не выполнялся.

## Осталось
- Переключить текущий запуск с localhost на `https://api.mator.uz` штатным `start:production`, сохранив локальную среду отдельно.
- Проверить реальный каталог, затем авторизованные Garage, совместимость, поиск, избранное, корзину и checkout до подтверждения заказа. Вход в реальный аккаунт выполняет пользователь.
- Отдельно отметить production-наблюдения: локальные результаты выше не считать production-подтверждением. Не переносить seed, не менять схему БД, не создавать реальные заказы или платежи.
- Тёмная тема/другие локали после этих исправлений, второй реальный аккаунт, Android и native rebuild остаются непроверенными.

В отдельный коммит не включены предшествующие изменения `garage-switch-row.tsx`, `compatibility-service.ts` и старые материалы `docs/audits/real-integration/`.
